# 算术与比较

本页覆盖算术运算与数值比较函数，共 17 个。

::: tip 整数与浮点提升
- `+` `-` `*`：所有操作数都是整数时结果也是整数；只要有一个浮点数，结果就是浮点数。
- `/`：**始终**返回浮点数，避免整数除法截断。
- 数值比较（`=` `<` `>` `<=` `>=`）支持整数与浮点数混用。
:::

---

## 算术运算

### `+` - 加法

签名：`(+ n1 n2 ...)`

对若干数字求和，支持任意多个参数。

```lisp
(+ 1 2 3)      ; => 6
(+ 1 2.5 3)    ; => 6.500000  含浮点 -> 浮点
(+)            ; => 0         无参返回 0
```

边界：参数含非数字时返回 `nil`。

### `-` - 减法

签名：`(- n1 n2 ...)`

从第一个数开始依次减去其余各数。单参数时取相反数。

```lisp
(- 10 3 2)     ; => 5
(- 5)          ; => -5        单参数取负
(- 5 2.5)      ; => 2.500000  含浮点 -> 浮点
(- 5 10)       ; => -5        允许结果为负
```

边界：无参返回 `nil`。

### `*` - 乘法

签名：`(* n1 n2 ...)`

对若干数字求积。

```lisp
(* 2 3 4)      ; => 24
(* 2 2.5)      ; => 5.000000  含浮点 -> 浮点
(*)            ; => 1         无参返回 1
```

边界：参数含非数字时返回 `nil`。

### `/` - 除法

签名：`(/ n1 n2 ...)`

除法，**始终返回浮点数**。依次除以后续各数。

```lisp
(/ 10 2)       ; => 5.000000  浮点数
(/ 1 3)        ; => 0.333333
(/ 20 2 2)     ; => 5.000000  链式除法
(/ 10 4)       ; => 2.500000
```

::: warning 除零
除数（或任一后续参数）为 `0` 时返回 `nil`，不抛异常。参数少于 2 个也返回 `nil`。
:::

### `mod` - 取模

签名：`(mod n1 n2)`

取余数，支持整数与浮点数混合。

```lisp
(mod 10 3)       ; => 1
(mod 10.5 3)     ; => 1.500000  浮点取模
(mod 10 3.0)     ; => 1.000000
```

边界：除数为 `0` 时返回 `nil`；参数数量不是 2 时返回 `nil`。

### `round` - 四舍五入

签名：`(round n [digits])`

对数字四舍五入，`digits` 为保留的小数位数，默认 0。

```lisp
(round 3.7)        ; => 4.000000
(round 3.14159 2)  ; => 3.140000
(round 7)          ; => 7         整数入参、digits=0 时返回整数
(round 7.5)        ; => 8.000000
```

边界：`digits` 必须为整数，否则返回类型错误；参数不是 1 或 2 个时报错。

### `sum` - 求和

签名：`(sum lst)`

对列表中的所有数字求和。空列表返回 `0`。

```lisp
(sum [1 2 3])      ; => 6
(sum [1.5 2.5])    ; => 4.000000
(sum '())          ; => 0         空列表
```

边界：列表元素含非数字时被忽略。

### `product` - 求积

签名：`(product lst)`

对列表中的所有数字求积。空列表返回 `1`。

```lisp
(product [2 3 4])   ; => 24
(product [2 3.5])   ; => 7.000000
(product '())       ; => 1         空列表
```

边界：列表元素含非数字时被忽略。

### `max` / `min` - 最大值 / 最小值

签名：`(max lst)` 或 `(max n1 n2 ...)`
签名：`(min lst)` 或 `(min n1 n2 ...)`

两种调用方式等价：
- 传入单个列表：`(max '(1 2 3))`
- 传入多个数字参数：`(max 5 3 8)`，通常与 `apply` 配合使用

```lisp
(max '(5 3 8 1))    ; => 8         列表形式
(min 5 3 8)         ; => 3         多参形式
(max 3.5 2)         ; => 3.500000
(min 3.5 2)         ; => 2.000000
(apply max '(5 3 8)) ; => 8        配合 apply
```

边界：无参数或空列表返回 `nil`。

## 数学函数

一元数学函数。**结果恒为浮点**（整型入参会先转 `Float64`）—— 开方、对数、
三角函数的结果不保证落在整数上，让返回类型随入参变化会让下游代码难以预测。

| 函数 | 说明 | 示例 |
|---|---|---|
| `(sin x)` `(cos x)` `(tan x)` | 三角 | `(sin 0)` => `0` |
| `(asin x)` `(acos x)` `(atan x)` | 反三角 | `(acos 1)` => `0` |
| `(exp x)` | 自然指数 | `(exp 0)` => `1` |
| `(log x)` | **自然对数** | `(log 1)` => `0` |
| `(log10 x)` | 常用对数 | `(log10 1000)` => `3` |
| `(sqrt x)` | 平方根 | `(sqrt 4)` => `2` |
| `(cbrt x)` | 立方根（负数可用） | `(cbrt -8)` => `-2` |
| `(pow a b)` | a 的 b 次方 | `(pow 2 10)` => `1024` |
| `(hypot a b)` | √(a²+b²)，大数不中间溢出 | `(hypot 3 4)` => `5` |

### 保留整数性的四个

`abs` / `floor` / `ceil` / `sign` 与上面那批**故意不同**：它们不改变量纲，
返回类型跟着入参走。

```lisp
(abs -3)      ; => 3      整数入参返回整数
(abs -3.5)    ; => 3.5    浮点入参返回浮点
(floor 3.7)   ; => 3      **返回整数**
(floor -3.2)  ; => -4     向负无穷
(ceil 3.2)    ; => 4      向正无穷
(ceil -3.7)   ; => -3
(sign -5)     ; => -1
(sign 0)      ; => 0
(sign 2.5)    ; => 1      浮点入参返回浮点
```

`floor` / `ceil` 返回**整数**是为了能直接当下标用：`(nth arr (floor 3.7))`。
返回浮点会让这种写法直接类型错。

### 定义域外的行为

**不抛异常**，返回 `nan` 或 `±inf` 让它在算式里传播：

```lisp
(log 0)        ; => -inf    对数在 0 处的极限
(sqrt -1)      ; => nan
(log -1)       ; => nan
(asin 2)       ; => nan
```

这是有意的：一批数据里只要有一个非法值，抛异常会让整批计算中断，而 `nan`
能让用户看到"这里坏了"并继续处理其余部分。判空由调用方做。

### 对数组逐元素生效

`sin` / `exp` / `sqrt` / `abs` / `floor` / `ceil` / `sign` 遇到实现了
`LispExternalElementwise` 的外部值时，会分派成逐元素运算 —— **不需要
`array-sin` 这类第二套名字**。数组能力由 `xisp-sci` 提供。

## 比较运算

### `=` - 相等

签名：`(= n1 n2 ...)`

**仅用于数字比较**，整数与浮点数可混合。所有参数相等返回 `true`。

```lisp
(= 1 1)        ; => true
(= 1 2)        ; => false
(= 1 1.0)      ; => true   整数与浮点可混比
(= 1 2 1)      ; => false  链式
```

::: warning 字符串请用 `string=?`
`(= 1 "1")` 返回 `false`。字符串相等比较请使用 [`string=?`](string)。
:::

### `!=` - 不等于

签名：`(!= n1 n2)`

数字不相等返回 `true`。

```lisp
(!= 1 2)       ; => true
(!= 1 1)       ; => false
```

### `<` `>` `<=` `>=` - 大小比较

签名：`(< n1 n2 ...)`
签名：`(> n1 n2 ...)`
签名：`(<= n1 n2 ...)`
签名：`(>= n1 n2 ...)`

支持链式比较，每对相邻参数都满足条件时返回 `true`。

```lisp
(< 1 2 3)      ; => true
(< 1 3 2)      ; => false   3 < 2 不成立
(> 3 2 1)      ; => true
(<= 1 2 2)     ; => true
(>= 3 3 1)     ; => true
(< 1 2.5)      ; => true    整数浮点混比
```

### `eq?` - 同一性比较

签名：`(eq? x y)`

比较两个值是否相等。支持符号、字符串、整数、布尔值与 `nil`。

```lisp
(eq? 'foo 'foo)      ; => true    符号
(eq? "a" "a")        ; => true    字符串
(eq? 42 42)          ; => true    整数
(eq? #t #t)          ; => true    布尔
(eq? nil nil)        ; => true
(eq? '(1 2) '(1 2))  ; => false   列表不按值比较
(eq? "a" "b")        ; => false
```

::: tip 与 `=` 的区别
- `=` 仅支持数字，且整数/浮点可混比（`(= 1 1.0)` → `true`）。
- `eq?` 支持符号、字符串、布尔等类型，但 `(eq? 1 1.0)` 与列表比较均返回 `false`。
:::
