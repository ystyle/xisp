# ystyle::xisp_examples

仓颉侧示例（**不发布**）。各示例是独立可执行包，演示解释器 API 的不同用法。

| 示例 | 内容 |
|---|---|
| `extension_demo` | `LispConvertible` / `LispDeserializable` 双向转换 |
| `options_usage` | `InterpreterOption` 配置组合 |
| `sandbox_demo` | 沙箱与权限限制 |
| `modules_demo` | 模块系统 |
| `modern_syntax` | 现代语法 |
| `match_demo` / `guard_test` | 模式匹配与守卫 |
| `test_destruct` / `test_pipeline` | 解构绑定与管道 |
| `quick_test` | 最小上手 |
