# Xisp REPL 操作指南

## 启动

```shell
# 启动增强型 REPL（默认，需要 TTY）
ystyle::xisp.cli

# 启动简单 REPL（非 TTY 环境自动回落）
ystyle::xisp.cli --simple-repl

# 直接执行代码
ystyle::xisp.cli -c '(+ 1 2 3)'

# 执行脚本文件
ystyle::xisp.cli script.lisp
```

## 输入编辑

### 基本编辑

| 按键 | 功能 |
|------|------|
| `←` `→` | 光标左右移动 |
| `Backspace` | 删除光标前字符 |
| `Delete` | 删除光标处字符 |
| `Home` / `Ctrl+A` | 光标到行首 |
| `End` / `Ctrl+E` | 光标到行尾 |
| `Ctrl+K` | 删除到行尾 |
| `Ctrl+U` | 删除整行 |

### 多行编辑

| 按键 | 功能 |
|------|------|
| `Enter` | 括号不平时换行，平衡时提交 |
| `Ctrl+Enter` / `Alt+Enter` | 强制提交（即使括号不平） |
| `↑` `↓` | 行间上下移动 |
| `Ctrl+J` | 等同于 Ctrl+Enter（强制提交） |

提交后，表达式被求值并打印结果。REPL 会清空编辑区，等待下一个输入。

### 历史导航

| 按键 | 功能 |
|------|------|
| `↑`（首行时）/ `Ctrl+P` | 上一条历史 |
| `↓`（末行时）/ `Ctrl+N` | 下一条历史 |

历史记录存储在 `~/.xisp_history`（最多 1000 条），跨会话持久化。

### 补全

| 按键 | 功能 |
|------|------|
| `Tab` | 补全符号名或函数名 |

补全源：当前环境绑定的变量 + 内置函数（define、lambda、let、if 等）。
匹配规则：前缀匹配，不区分大小写。唯一匹配时自动补全，多匹配时显示候选列表。

### 特殊操作

| 按键 | 功能 |
|------|------|
| `Ctrl+C` | 取消当前输入，回到新行 |
| `Ctrl+D` | 空缓冲区时退出 REPL |
| `Esc` | 空缓冲区时退出，非空时清空缓冲区 |
| `Ctrl+L` | 清屏重绘（*待实现*） |

## REPL 命令

所有命令以 `,` 开头：

| 命令 | 功能 |
|------|------|
| `,exit` / `,quit` | 退出 REPL |
| `,help` | 显示帮助信息 |
| `,env` | 查看当前环境变量 |
| `,history` | 查看历史记录 |
| `,lang zh` | 启用中文关键字 |
| `,lang en` | 切换回英文关键字 |

### 中文关键字

启用 `,lang zh` 后，可以使用中文关键字：`(定义 x 42)`、`(过程 (x) (* x x))`、`(如果 (> x 0) ...)`。

## 输出

- 求值结果使用 ANSI 颜色着色输出：
  - 数字（Int/Float）：黄色
  - 字符串：绿色
  - 符号：蓝色
  - `nil`：灰色
  - 错误：红色粗体 + 调用栈
- `nil` 结果不打印

## 自检

- 括号平衡实时检测，不平时继续等待输入
- 非 TTY 环境（管道重定向）自动回落为简单 REPL（`readln` 模式）
- `--simple-repl` 标志强制使用简单 REPL
